# 【Trae&AI项目】时间轴挑战 · 新闻排序游戏 (模块化版本)

这是一个交互式新闻时间线排序 Web 小游戏，采用高度模块化的原生 JavaScript 开发，无任何第三方依赖。

## 游戏核心功能

1.  **丰富的新闻库**：预设了 24 条涵盖政治、科技、体育、文化、科学、经济等领域的重大新闻事件。
2.  **交互式排序**：支持 PC 端鼠标拖拽和移动端触摸操作，实时调整卡片顺序。
3.  **多级难度模式**：
    -   **简单**：5 条新闻，适合新手体验。
    -   **中等**：8 条新闻，挑战中等。
    -   **困难**：12 条新闻，专为历史达人设计。
4.  **实时验证系统**：点击“提交答案”即可即时获得反馈。系统会高亮显示正确和错误的卡片，并为错误项提供正确的时间提示。
5.  **排行榜系统**：使用 `localStorage` 记录各难度下的最佳成绩（综合评分基于准确率和完成时间）。
6.  **响应式布局**：完美适配手机、平板及电脑各种屏幕尺寸。

## 目录结构 (模块化设计)

项目按职责进行了彻底拆分，确保高内聚、低耦合：

```text
/
├── index.html          # 入口 HTML 文件
├── README.md           # 项目文档
└── src/                # 源代码目录
    ├── main.js         # 应用入口与全局挂载
    ├── core/           # 核心业务逻辑
    │   ├── game.js     # 游戏流程控制 (开始、提交、重置等)
    │   └── state.js    # 全局状态管理
    ├── data/           # 数据访问层
    │   └── news_db.js  # 新闻事件数据库 (可随时扩展)
    ├── ui/             # UI 组件与渲染层
    │   ├── renderer.js # DOM 渲染与屏幕切换
    │   ├── drag-drop.js# 拖拽交互逻辑 (支持桌面/移动端)
    │   └── style.css   # 全局样式与动画
    └── utils/          # 通用工具函数
        ├── helpers.js  # 格式化与计算工具
        └── storage.js  # 本地存储封装
```

## 技术架构优势

-   **ES Modules**: 利用原生浏览器模块系统，实现模块间的依赖管理，避免全局变量污染。
-   **职责分离 (SoC)**: 游戏逻辑、数据处理、UI 渲染相互独立，修改功能仅需变动对应模块。
-   **可扩展性**: 开发者可以轻松在 `src/data/news_db.js` 中添加新事件，或在 `src/utils/` 中添加新功能。
-   **零依赖**: 仅使用 HTML5, CSS3, JavaScript，运行效率极高。

## 运行与维护

1.  **运行**: 由于使用了 ES Modules，建议在本地启动一个静态服务器运行（如 VS Code 的 Live Server 插件），直接双击打开 HTML 可能会因 CORS 策略导致模块无法加载。
2.  **添加新闻**: 编辑 `src/data/news_db.js`，按现有格式向 `NEWS_DB` 数组中添加对象即可。
3.  **修改样式**: 编辑 `src/ui/style.css`。
4.  **调整逻辑**: 编辑 `src/core/game.js` 或相关模块。

## 升级指南

如果您是从单文件版本升级而来的：
-   **数据定义**: `NEWS_DB` 现在需要显式 `export` 并在需要的地方 `import`。
-   **全局函数**: HTML 中的 `onclick` 事件调用的函数现在在 `src/main.js` 中被统一挂载到 `window` 对象下。
-   **CSS 引用**: 样式已从 `<style>` 标签移至外部 CSS 文件。
