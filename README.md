# 时间轴挑战 · 新闻排序游戏

一个基于原生 JavaScript 实现的交互式时间线排序小游戏。
玩家需要将随机打乱的重大新闻事件按时间先后顺序排列，系统会根据准确率与用时进行评分，并记录排行榜成绩。

---

## 🎮 项目简介

本项目旨在通过“游戏化学习”的方式，帮助用户回顾和理解历史事件的时间脉络。
系统从新闻数据库中随机抽取若干事件，打乱顺序后展示为卡片，玩家通过拖拽完成排序挑战。

👉 支持 PC 端拖拽与移动端触摸操作，适配多设备使用。

---

## ✨ 核心功能

### 1. 📰 丰富的新闻事件库

* 内置 **100 条全球重大新闻事件**
* 覆盖领域：

  * 政治 / 科技 / 经济 / 体育 / 文化 / 科学
* 时间跨度：**2000 年 – 2026 年**

---

### 2. 🎯 多难度模式

| 难度 | 新闻数量 | 说明       |
| -- | ---- | -------- |
| 简单 | 5 条  | 适合新手体验   |
| 中等 | 8 条  | 需要一定历史认知 |
| 困难 | 12 条 | 高难挑战     |

---

### 3. 🧩 拖拽排序交互

* PC：原生 Drag & Drop API
* 移动端：自定义 Touch 事件模拟拖拽
* 实时更新排序序号

---

### 4. ✅ 即时验证系统

点击“提交答案”后：

* 正确卡片 → 绿色标记 ✔
* 错误卡片 → 红色标记 ✖ + 显示正确时间
* 显示：

  * 正确率
  * 用时
  * 综合评分

---

### 5. 🏆 排行榜系统

* 基于 `localStorage` 本地存储
* 按难度分别记录成绩
* 每个难度保留前 10 名

---

### 6. 📱 响应式设计

* 适配手机 / 平板 / PC
* 支持触屏操作
* 统一视觉风格（简约 + 现代）

---

## 🧠 游戏机制说明

### 题目生成流程

1. 从新闻库随机抽取 N 条事件
2. 按时间排序 → 生成正确答案
3. 再次打乱 → 作为玩家题目

---

### 评分机制

综合评分由以下因素计算：

* 准确率（核心权重）
* 完成时间（越快越高分）
* 难度加成（困难模式分更高）

## 🧩 技术实现

### 核心技术

* HTML5 / CSS3 / JavaScript（ES5+）
* 无任何第三方依赖（纯原生实现）

---

### 架构特点

#### 1️⃣ 命名空间模块化（GameApp）

所有功能挂载在全局对象：

```js
window.GameApp = {}
```

避免全局污染，同时实现模块解耦。

---

#### 2️⃣ 职责分离（SoC）

| 模块      | 职责   |
| ------- | ---- |
| core    | 游戏逻辑 |
| data    | 数据   |
| ui      | 渲染   |
| utils   | 工具   |
| storage | 持久化  |

---

#### 3️⃣ DOM 驱动状态

* 卡片顺序直接由 DOM 决定
* 提交时读取页面顺序进行校验

## ⚠️ 已知问题

* 使用 `sort(() => Math.random())` 随机打乱，不完全均匀
* 部分事件仅精确到“月份”，同月事件顺序存在歧义
